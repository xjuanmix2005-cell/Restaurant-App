# Restaurant App

This is my restaurant project for SODV2201 (Assignment 1, the React frontend).

## Features
- Shows the menu with search and filters
- Cart and orders (pickup or delivery)
- Table reservations
- AI chat (simulated)
- Admin page to manage the menu, orders and reservations

## How to run it
1. Go to the frontend folder
2. npm install
3. npm run dev

Made with React, Vite and React Router.
